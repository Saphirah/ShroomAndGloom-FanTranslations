SHROOM AND GLOOM FAN TRANSLATIONS

Windows x64 · Steam build 25442225.

Close the game, open the installer, select the detected Steam folder and install.
Select a language in the game settings. All available language packs are installed initially.

The mod checks for published updates at startup and downloads only changed language
packs. Offline keeps the installed translations. Code updates use the installer.
The first BepInEx launch also requires Internet to prepare Unity interfaces.

Use the same installer to uninstall. Original game files and saves are preserved.
Other mods and locally modified files are protected.

Configuration: BepInEx/config/de.shroomandgloom.german.cfg
[Language] StartupLocale = auto respects the saved in-game language selection.
[Aktualisierung] SprachpaketBeimStart = false disables automatic language updates.

Additional translations are AI-assisted with a separate editorial pass and static
checks. Community corrections are welcome. Existing original game fonts are retained;
Noto fallbacks support additional scripts and are private to the game process.
